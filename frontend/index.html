The Problem

Students spend valuable time hunting for background music that fits their exact momentary mental state.

menu_book

Late-Night Study

Need low-distraction, lo-fi or ambient soundscapes during exam prep. Genre search gives too broad results.

bedtime

Sleep & Wind-Down

Soothing, minimally percussive sound environments. "Relaxing" playlists are often too energetic.

directions_bus

Commute & Transit

Rhythmic, medium-to-high energy beats. Standard algorithms loop the same 50 songs.

Our Solution

Type exactly what you need — "calm lo-fi for 3 AM calculus revision" — and Moodwave finds 10 tracks with one-line explanations of why each one fits.

System Architecture

Two-layer system: FastAPI backend with semantic-ID indexing, Android / Web client with offline cache.

How the Pipeline Works

    

      

        
1

        

          
Natural Language Query

          
The user types a prompt like "calm lo-fi for late-night revision" or taps a mood chip.

        

      

      

        
2

        

          
Dual-Path Intent Parser

          
A structured Gemini LLM extractor (when available) or a deterministic rule-based regex/keyword parser extracts moods, genres, avoid_genres, and context.

        

      

      

        
3

        

          
Semantic ID Prefix Filtering

          
Each track has a hierarchical Semantic ID (e.g. 14-08-31). Familiar mode filters by shared prefix. Non-habitual mode deliberately diverges.

        

      

      

        
4

        

          
Cosine Similarity & Reranking

          
Candidate vectors are scored by cosine similarity to the query embedding, then adjusted by session feedback (skips penalize, saves/replays boost).

        

      

      

        
5

        

          
One-Line Explanation

          
Every track gets a transparent rationale directly linking the extracted intent to the track's tags: "Matched calm mood with ambient lo-fi genre."

        

      

    

  









  

    
Safety & Reliability

    
Zero hard failures. Graceful degradation at every layer.


    

      

        wifi_off
        
Backend Down

        
Shows cached results with Offline banner, or a Retry button if no cache.

      

      

        warning
        
LLM Unavailable

        
Falls back to rule-based parser. Response still returns 200 with source: "rules" and a Degraded banner.

      

      

        block
        
Prompt Injection

        
Injection strings are treated as ordinary text. The system instruction is never changed. Query is user data only.

      

      

        speed
        
Rate Limiting

        
After 60 req/min → 429 with Retry-After header. Banner shows countdown.

      

      

        security
        
Privacy

        
LLM receives only the query text. No user_id, no device ID, no listening history leaves the device.

      

      

        policy
        
Policy Guard

        
Explicit/harmful queries are blocked before the LLM is called, returning a neutral message.
